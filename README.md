# 💫 About Me:
I'm a Full-Stack Developer, Open Source enthusiast, and the founder of CodeSpire Solutions — an independent software studio focused on creating modern applications, developer tools, and practical software solutions.

Currently, I'm pursuing my Abitur in Computer Science in Germany while spending most of my free time designing, building, and maintaining open-source projects. I enjoy turning ideas into polished software, exploring new technologies, and solving problems through code.

I believe software should be intuitive, accessible, and built to last. Whether it's a developer tool, a desktop application, or an experimental hardware project, my goal is always the same: create something that is useful, well-designed, and enjoyable to use.
